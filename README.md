# 雅思词汇 · 听说读写

基于 [hefengxian/my-ielts](https://github.com/hefengxian/my-ielts) 的词汇和考点词资料，加上中文方向的练习、按间隔复习的高强度训练，以及听力、阅读、写作、口语练习：100 句翻译自动判分、时态语态练习、利弊类作文讲义。阅读文章、写作和口语题目为原创；不包含剑桥真题等受版权保护的题目和音频。

阅读页的“题库”需要使用者自己导入本机生成的题库文件，题库内容不在这个仓库里。拼写词典来自 SCOWL，许可说明在 data/dict-en.js 文件头。

这里只放构建好的静态网站，由 GitHub Pages 发布。学习进度保存在各自浏览器里（IndexedDB），可以在设置里导出 / 导入。
